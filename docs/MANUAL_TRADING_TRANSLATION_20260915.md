# 把人工日内交易判断转成可核对的 SNDK 策略

用户截图里的 SNXX 买卖是用户本人手动操作。它用于说明希望达到的节奏：分批买入、确认后加仓、持有上涨段、走弱后退出。本次研究交易对象是 SNDK 股票。没有用户的精确成交时间和股数，不能把截图直接当训练标签，也不能计算用户那组交易的收益。

## 已完成的实现

- `backend/app/alpha/support_resistance.py` 提供19列支撑压力、开盘区间、确认高低点、突破及回踩描述。
- `holding_policy.py` 的 `support_context` 在原量价、同时间段相对成交量、市场和行业参考特征上追加这些列。训练和候选推断使用同一函数。
- 继续预测5/15/30/60分钟累计收益，由既有多周期组合规划决定目标仓位；另一组对照加入以前向校准误差估计的风险。没有把支撑位写成必买规则，也没有把历史高点写成必卖时点。
- 生成两天、三组候选的实际模拟买卖点、每笔股数、持仓、预测及盈亏。当前运行中的模型没有被替换，UI和README未改。

这只是把人工判断中的可观察信息转成机器输入，不代表机器已经学会用户的交易能力。尤其是“多加几个特征”未必解决目标函数、校准或退出方式的问题。

## 人的观察如何对应数据

| 人工观察 | 可以计算的输入 | 用途与限制 |
|---|---|---|
| 回踩某价位后稳住 | 当时已知的前日高低、开盘区间、确认低点、跌破后收回距离 | 判断候选入场；低点需等待确认，不能提前知道全天底部 |
| 突破后有没有人继续买 | 突破与回踩距离、同时间段相对成交量、价格推进幅度、市场相对强弱 | 区分有延续的突破和迅速回落；总成交量不能确定机构身份 |
| 先买一点，走对再加 | 多周期预期收益、校准误差、现有仓位、波动及股票间相关性 | 联合配仓；本次股数由模型和资金决定，不按截图写死 |
| 持有一段，而非每根K线翻向 | 15/30/60分钟预测曲线、维持仓位与改变仓位的成本 | 原规划器已经使用；两天结果显示短时反复交易仍未解决 |
| 接近压力位后分批出 | 受阻幅度、较低高点、回落、剩余预测收益 | 测试退出质量；碰到某价位本身不证明应该卖出 |
| 期权是否活跃 | 延迟Call/Put成交量、到期日与行权价分布、带日期的OI | 待建立完整留存；OI不带看涨方向，也不能识别机构买入 |

## 两天对照结果

9月14日为完整交易日；9月15日仅到**15:50美东**，仍有估值中的未平仓股数，不是当日最终盈亏。

| SNDK模拟净盈亏 | 原Context | 加支撑压力 | 加支撑压力与误差风险 |
|---|---:|---:|---:|
| 9月14日 | +$107.66 | −$126.72 | −$95.05 |
| 9月15日截至15:50 | −$262.61 | −$182.33 | −$147.19 |
| 两次独立实验结果之和 | −$154.95 | −$309.05 | −$242.24 |

9月14日四股组合起始资金$47,006.42；9月15日$47,958.07。每天独立零持仓开始，**不是连续账户复利**。SNDK资金按四股组合动态分配，不是将以上本金全部用于SNDK。规划成本2bps、实际模拟成交单边摩擦5bps，两者均为假设，非确认的Alpaca扣费。滑点已包含在模拟成交价，净盈亏不重复扣减。未验证借券可得性、真实成交概率和额外借券/规费。

加风险的候选今天比原Context少亏$115.42，但昨天少赚/多亏$202.71，两次结果之和反而差$87.28。不能用今天改善宣称新Alpha成功。完整四股组合结果见[原始实验报告](../reports/manual_style_research_20260915/REPORT.md)，三组候选两天的组合结果也均亏损。

## 仍失败的具体交易

以下均为模型模拟，价位为未加滑点的参考价。含滑点成交价与每笔股数见CSV。

- **9月14日09:50**：新风险候选仍追买9股，参考$1,546.70；09:55又卖11股，参考$1,524.79。它缩小了部分风险，却没有识别这次假突破。
- **9月14日13:30之后**：新候选先卖完剩余2股，随后13:45、13:50、14:00又在更高价加回。持有上涨段的质量仍差。
- **9月15日上午**：先做空并在10:15平空，净亏约$65.63；10:20参考$1,564.22转多4股，至10:45卖完，再亏约$41.26。减亏主要来自仓位变化，方向错误依然存在。
- **9月15日11:15与11:45**：两次买入都在五分钟后退出，分别净亏约$10.19和$7.36。仅增加支撑压力输入还不足以形成用户希望的持仓节奏。

## 期权实际进度

完成[免费期权数据审计](OPTIONS_DATA_AUDIT_20260915.md)。本账户SNDK/TSLA样本的合约资料、免费indicative快照及较早历史K线返回成功。不过样本OI日期均为9月11日；9月15日下午取得的快照不能倒填昨天或今天早盘。免费indicative报价是修改过的衍生报价，成交有15分钟延迟。[Alpaca官方说明](https://docs.alpaca.markets/us/docs/historical-option-data)

这次两天实验**没有加入期权或L1输入**。可建设完整合约池的延迟成交量、Call/Put活动比例和每天OI留存，再按真实可用时间做对照。两份单Call样本不能计算全链Put/Call比例，更不能推导可信的Dealer Gamma或机构资金方向。

## 验证与下一轮研究依据

支撑特征和统一训练/推断契约的9项测试通过。包括追加未来行情不改变过去、确认点可用时间、缺失数据、提前收盘以及原Context列保持一致。六条模拟路径以成交现金流加期末库存独立重算，盈亏一致；训练与校准标签均早于目标交易日。这两天已经看过，属于回顾开发，不是未触碰的样本外证明。

下一轮应围绕具体失败检查：原始预测经过校准后是否错误翻向；退出后很快高价回补是否来自过短的收益目标；同一预测下持仓调整是否比继续持有更有价值。记录全部尝试，以后续未用于修改的日期验证，不能把这两天调到漂亮后当作泛化成绩。期权数据先积累可用时间记录，再评价是否增加信息。
