# ML 仪表盘数据审计

审计日期：2026-09-13。

## 结论

旧 ML 仪表盘中发现八类无法作为真实策略证据的数据。相关布局、图表和控件继续保留；无法验证的结果改为 `—` 或清楚的待验证状态。

| 类别 | 旧显示问题 | 当前处理 |
|---|---|---|
| 胜率与期望收益 | 固定 P_win、E[R] 和 Kelly 数字 | 没有带版本的校准模型产物时显示 `—` |
| 校准结果 | 固定 Brier Score 和五个“吻合”分箱 | 清空结果，等待真实样本外预测与标签 |
| 市场体制 | 随机变化的 HMM、Hurst 和动量状态 | 显示待验证；历史涨跌另列为行情事实 |
| 微观结构 | 用随机数生成 OFI、Microprice、VPIN | 删除随机生成；真实 L1 状态由采集器单独显示 |
| L2 盘口 | 固定价格和随机五档深度 | 清空五档；没有 L2 数据源时显示不可用 |
| 模型解释 | 固定 LightGBM 特征重要性 | 清空权重，等待对应模型产物与特征版本 |
| 执行指标 | 固定 SOR 成交率、逆向选择与 bps 收益 | 清空，等待订单与报价对齐后的执行研究 |
| 收益与性能 | 固定模拟净收益、C++ 延迟数字及随机订单 | 清空；手动沙盒只记录输入，不产生假订单或假盈亏 |
