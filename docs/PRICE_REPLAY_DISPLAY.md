# 价格线与买卖点回放展示

用户授权用价格折线、买卖标记和股数替换复盘大屏主图，保留 Dynamic Replay 与既有交互。该变更仅涉及数据展示，不改变交易模型或下单逻辑。

## 页面

- `TradeComparisonPanel` 默认显示新的价格回放；经典规则轨迹与K线保留在旁边的切换按钮。
- `PriceActionReplayChart` 显示蓝色价格折线、橙色OHLCV均价代理、B/S/C/X及股数、成交量、持仓和净盈亏。支持股票、日期、研究模型、播放/暂停、倍速、进度拖动、时段与缩放。
- 原Dynamic Replay保留沙盒、播放按钮、倍速和其他页面结构，图表默认改为价格线与均价代理。K线及EMA可通过图例开启。
- 股票在两个展示区域联动。研究回放和券商归档的日期独立选择，因为保存的日期范围可能不同；不能把券商归档日期强塞给研究回放。
- 修复原 `trade_comparison` 页面重复渲染两套复盘面板的问题。

## 数据

新增只读接口：

```text
GET /api/dashboard/price_replay?ticker=SNDK&date=2026-09-15&variant=levels_error_risk
```

当前可移植数据包位于 `backend/data/price_replay/`，覆盖SNDK、TSLA、NVDA、PLTR，9月14日与9月15日，Context/支撑压力/支撑压力与误差风险三种研究模型，共24份。该接口读取已保存数据，不训练模型、不查询券商、不自动生成交易。缺失组合显示不可用。

9月15日仅截至15:50美东，仍保留未平仓库存；不能标成完整日或实际账户盈亏。单边5bps为模拟摩擦，已体现在模拟成交价，不能再次从净盈亏扣除。组合期初资金不等于某只股票独占的资金。

价格时间使用已完成5分钟K线的可用时刻，成交使用实际模拟执行时间。持仓阶梯直接来自成交事件。保存的K线收盘估值发生在同刻下一根开盘成交之前，因此前端追加同刻成交后的现金与库存估值，使回放不会出现新仓位却仍显示成交前盈亏的情况。重置/播放不显示尚未发生的成交标记。

原Dynamic Replay保留券商归档来源。其真实成交标记现在按完整时间戳定位，不再要求成交分钟恰好等于5分钟K线时间点。

## 更新研究数据包

使用导出脚本读取经过校验的研究产物，命令行参数见：

```bash
python3 scripts/export_price_replay_bundle.py --help
```

不要手动修改保存的盈亏或股数；清单哈希不匹配的产物会被拒绝展示。新报告加入页面需要更新数据包，而不是将当前两天样本假装成实时推断。
