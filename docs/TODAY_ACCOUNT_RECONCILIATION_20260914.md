## 错误原因与修复

旧显示账本有 3,103 条订单镜像，存在没有正确抵消的旧库存。原 FIFO 用这些旧库存配对今天 SNDK 卖出，错误显示 -$2,313.43；同时缺少 TSLA 开空记录，显示 Unknown basis。

新显示从当前账户分页读取全部可用 FILL 活动。本次共 11,192 条，按每笔真实部分成交时间配对，并对照券商当前持仓。支持实际返回的 sell_short 类型，按活动 ID 去重，再按订单与美东日期汇总。

只修正今日展示和今日汇总，不删除或静默重写历史文件。若活动尚未核对完成或库存不一致，当前行明确显示待核对，不能沿用错误盈亏。新模块没有提交/撤销订单，也不改变 live_runner 的交易方向。

此处是券商成交 FIFO 对账，不是税务账单。历史税务成本和企业行动仍需官方结算证据。当前这四个订单的已实现盈亏与账户日变动已对上。
