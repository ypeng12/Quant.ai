### 7. 我们真正要得到的消息，以及 NLP 应怎样处理

目标是一条有证据、公司关联和时间边界的研究记录，而非只有一个情绪分数。

| 消息类型 | 希望提取的具体内容 | 对待方式 |
| --- | --- | --- |
| 财报／经营指引 | 公司、报告期、已公布数值、相对旧指引的变化、原文证据 | 没有同期一致预期就不写“超预期” |
| 合同／产品／产能／融资 | 主体、动作、金额或规模（原文存在时）、确认还是传闻、发生与报道时间 | 匿名传闻单独标记；新闻新发表不自动等于事件首次发生 |
| 监管／诉讼／供应链 | 哪家公司直接受影响、事件阶段、事实与分析观点 | 不让模型补造因果或未公开事实 |
| 行业／市场评论 | 讨论的行业、依据、所引用价格窗口 | 提供背景，与公司特定事件分开 |
| 富途观点 | 针对哪个标的、看多／看空／不明确、强度、条件、预测期限、愿望／疑问／复盘／未来判断 | 同帖可以对不同公司有不同方向，条件与期限未知则留空 |
| 行情回顾／重复跟进 | 已发生涨跌、重复事件 ID、新增事实是否存在 | 可以保留作单独基线，不冒充未反应的新信息 |

统一记录分四层：

1. **来源层**：`source, source_id, source_url(nullable), query_symbol, raw_text, language, content_hash, request_started_at, response_received_at, first_seen_at, published_at, updated_at`。发布方没提供的字段留空；研究原文与展示摘录分开。
2. **信息层**：`target_symbol, relevance, event_type, event_cluster_id, evidence_excerpt, confirmed_or_reported_or_rumor, stance, condition, stated_horizon, retrospective_flag, extraction_version`。
3. **预测层**：`feature_cutoff, extraction_completed_at, prediction_completed_at, available_at, model_version, training_cutoff, horizon, predicted_score, calibration_status, expected_excess_return(optional), sample_coverage, missing_reason`。抽取置信度不是上涨概率；实际可交易时间不得早于响应收讫、抽取完成和预测完成中的最晚时刻，不能只凭新闻已收到就假定信号已算完。
4. **结果层**：`entry_reference_time, exit_reference_time, stock_return, benchmark_return, label_status, execution_cost_assumption`。结果层与当时预测输入隔离。

NLP 实施次序：先主体关联／去重／观点类型抽取；英文比较原始 FinBERT 情绪、Loughran–McDonald 词典、TF-IDF 线性模型、冻结编码器加价格标签分类头；课程第 2 阶段完成价格标签微调基线，并与相同时间切分的动量基线对照。中文先做立场词典基线和固定提示的结构化抽取，再与冻结中文／多语言编码器比较；模型选型以这批简繁、粤语、反讽语料的验证为依据，不套用英文 FinBERT。文本模型版本、提示和阈值均冻结并缓存。此次未调用外部模型处理这些样本。

富途先聚合同一股票过去 60 分钟已收到的去重文本，计算有明确方向的帖子净值 `(看多数−看空数)/(看多数+看空数)`、有效样本量、不明确比例、分歧和相对过去分布的变化。分母为零或覆盖低时显示缺失／低覆盖，不填中性；没有作者字段就不能按独立用户统计。条件预测单列特征，暂不强行计为无条件看多看空；重复文不加权，长文章也不按字数获得更多票。

比较顺向、反向及情绪与过去涨幅的交互，控制过去收益、波动、时段和市场／行业走势。重点检验“同样涨幅下更亢奋是否意味着更弱的后续收益”，不预设散户必然错误。

### 9. 从消息到 Quant.ai A/B：统一资金，处理好周期差异

**主研究目标为未来 60 个交易分钟超额收益，15 分钟为辅助；富途下一交易日关系是后续独立实验。** 第一版不把次日预测混入当天必须平仓的策略，也不把盘前／盘后消息硬塞入常规时段标签。这样会丢掉一些重要财报窗口，报告其数量，并把隔夜模型作为下一阶段任务。

现有 Quant.ai 的五分钟更新与预测接口必须单独处理：60 分钟收益或情绪概率不能直接当五分钟预期收益，不能机械除以 12。拟定集成方式是：保留 A 的基础预测和优化器；B 读取截至当时的文本分数、信号年龄与行情状态，在训练期通过校准层学习**下一五分钟相对基础预测的增量**，然后以 `mu_B_5m = mu_A_5m + delta_text_5m` 接入同一优化器。五分钟是预登记的交易接口辅助标签，60 分钟仍是论文主标签；两者分别评价。

校准层使用时间前推生成的训练外文本分数拟合；同样，残差目标使用的基础预测 `mu_A` 也必须来自当时仅用过去数据训练的版本，不能只让文本分数训练外而使用量价模型的训练内预测。最初用 Ridge／线性校准，正则化与缺失回退规则在验证期固定；缺新闻可回退到 A 的预测，并记录回退。开发和样本外诊断另加“同等校准层但屏蔽文本”的消融，保留相同量价输入、训练预算与约束，以区分文本贡献和新增行情校准本身的贡献；主要两组 A/B 仍单独报告。若不能可靠校准，则保留研究分数，不直接改变仓位。本次尚未实现这层，也没有任何已验证的文本收益增量。

| A/B 项目 | 预登记安排 |
| --- | --- |
| 初始资金 | 两组各 $50,000 模拟资金，不额外出入金；金额是新实验配置，不重置现有券商账户 |
| 起点 | 同一时刻、相同现金、零初始持仓；共同股票池、数据、风险上限和成交规则 |
| A | 冻结的现有 Quant.ai 模型／策略版本 |
| B | 同一基础模型及优化器＋冻结的文本增量模块；预测不同可以产生不同持仓 |
| 对照顺序 | 开发期分别比较新闻、富途、合并；最终测试前选择并冻结一个 B，不看测试结果换赢家 |
| 富途不足时 | 第一轮 B 明确只含新闻；待富途积累并完成训练后开新的独立 A/B 轮次，不能中途换 B 并合并业绩 |
| 更新政策 | 第一轮冻结模型权重；若设滚动重训，需事先固定日程和只用过去数据，A/B 的共用基础模型同步更新 |
| 执行 | 先同步影子／模拟账本；共同延迟、整股、交易时段、风控与成本口径，部分成交／未成交均记录 |
| 收益口径 | 同一时点现金＋按统一行情估值的持仓，计入已实现、未实现盈亏和成本；不只挑已平仓盈利单 |
| 主指标 | `期末净值_B − 期末净值_A`，同时报告收益率相差多少个百分点 |
| 配套指标 | 最大回撤、总／净敞口、换手、成本、按日净值差和股票／事件贡献集中度 |
| 时间 | 冻结后连续约 40 个交易日为首轮前瞻目标，期间不择优停表；依课程截止日提前登记实际终点 |

当前报价权限不足以声称精确复现实盘滑点。历史模拟须固定并报告成本假设，另做成本敏感性；前瞻记录真实数据延迟与可得报价。无法验证的成交质量列为限制，不能用降低成本假设制造盈利。需要做空时两组使用相同、实际可验证的借券约束；缺证据则统一限制，不给 B 隐含优势。

历史 12 个月按时间开发，留出更晚的验证与历史样本外诊断；本项目已查看部分历史，不能将其称为从未碰过的最终盲测。事件簇、多股票同稿、跨界标签窗口分组清除；标准化、阈值、概率校准只在训练／验证期拟合。真正最终对照以冻结后尚未发生的数据为主，置信区间按交易日及事件相关性处理，不把每个五分钟或每篇重复报道当独立样本。

### 10. 目标产品、阶段交付和本次结论

最终目标是**有市场／行业背景的公司信息与预测模块**，并能证明其加入 Quant.ai 后的净收益差。消息情绪、价格影响预测、事后结果分栏展示：

- `Data Coverage`：各股票有效消息数、首次收到时间、延迟、缺失、采集状态。
- `Company Signals`：公司事件与证据、社区观点、预测窗口、分数／校准状态；缺数据显示 `Insufficient data`。
- `Event Study`：当时可见文本、个股与基准曲线、假设入场点、事后收益；未结束显示 `Pending`。
- `A/B Comparison`：两组资金、版本、净值曲线、净收益差、回撤、成本，以及导致持仓变化的事件。

沿用现有 React／FastAPI 结构，2026-10-09 已将 Financial Sentiment 集成到 Quant.ai 主导航第二项，页面与公开 README 使用英文。公开汇总来自试采档案，原文与账户数据保留本地；上述预测、事件研究和 A/B 页面尚未实现。训练离线，页面读取版本化产物；不把模型训练放进实时交易循环。未训练显示 `Not trained`，未评估显示 `Not evaluated`。

| 阶段 | 具体交付 | 完成判据 | 状态／预计工作量 |
| --- | --- | --- | --- |
| A：真实小样本审计 | 本报告、原始响应、字段与内容检查、价格配对 | 数量可复算，成功和失败都有证据 | 本次完成；全年覆盖、延迟与许可仍待验证 |
| B：持续留存与扩大覆盖 | 四股富途采集；20 公司新闻覆盖审计；持久化与版本管理 | 连续 7 个交易日能报告成功、漏采、去重与到达时间 | 尚未开始；实现约 3–5 个工作日，观察时间另算 |
| C：NLP 与预测基线 | 500 条复核目标、情绪／价格标签对照、时间验证 | 有独立评价、覆盖率、失败案例；不以收益反推清洗规则 | 数据齐备后约 2–3 周，独立人类复核需项目成员参与 |
| D：交易集成与冻结 | 五分钟增量校准、影子账本、完整 A/B 注册 | 相同资金／约束；决策与输入版本可回放；无未来输入 | 约 1 周，可与 C 后段部分重叠 |
| E：前瞻结果与报告 | 约 40 交易日 A/B，预测及收益贡献分析 | 如实报告输赢、幅度、回撤和不确定性 | 约 8 个交易周；不是保证在该时长内证明长期盈利 |

本次思考后的优先级：**新闻与行情已经能跑通真实数据配对，优先做主体识别和事件去重；富途尽早积累前瞻档案，但先研究帖子，不研究用户；SEC 暂作证据索引；实时行情权限与实际延迟在交易集成前解决。** 不以 187 篇新闻、120 条帖子或 90 个标签宣称有 Alpha。真正希望得到的是：信息在收益发生前被记录，模型确实改变决策，且相同资金条件下收益改善有可追溯证据。
