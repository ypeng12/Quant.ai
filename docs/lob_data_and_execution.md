# LOB 数据、预测与执行：项目约定

更新：2026-09-13。以下区分真实观测、研究假设和当前已完成的实现。

## 数据能证明什么

OHLCV 不能还原订单簿。旧 Wave 特征根据 K 线、成交量和估算价差构造，必须称为代理指标，不能称为实际挂单量、主力扫盘或真实 OFI。这并不证明量价特征必然亏钱：它们是否有预测价值，需要独立的因果验证。

当前 `alpaca_l1_capture.py` 记录的是带来源、时间戳的买一卖一报价更新和成交，不是每张限价单的新增、修改、撤销及排队位置。真实 L1 不等于 L2/L3，也不足以准确重建个人订单在完整队列中的位置。经过验证的官方历史报价也是有效数据来源；WebSocket 并非唯一来源。

新看板将旧历史代理图与真实 L1 留存快照分开。快照展示来源、feed、报价时间、价格和数量单位；快照存在不代表此刻连接正常。单个快照只能给出报价价差、买卖一数量失衡和微价格偏移，无法给出事件变化 OFI、完整队列或交易胜率。没有可用报价时，展示不可用状态，不填入缓存或 K 线估计。

## 有效周期需要测量

不能给所有 OFI 指标指定统一的几秒或一两分钟半衰期。瞬时盘口状态、区间累计 OFI、不同股票与 feed 的预测表现可以不同。

Cont、Kukanov 和 Stoikov 的研究使用报价与成交数据分析同区间价格变化与 OFI，并检查了从约半秒以下到十分钟的聚合尺度。**解释同一区间的价格变化不等于预测未来收益**；这既不能证明五分钟 OFI 无效，也不能证明它有可交易的预测能力。[原论文 §3.1–3.2](https://arxiv.org/html/1011.6402)

项目应预先登记不同观测窗口和未来收益周期，用完成的事件计算特征，随后按可执行价格评估；先衡量预测误差、相关性和成本后的表现，再决定是否用于五分钟配仓或更短周期的执行。

## 成本与 Maker/Taker

四股 `context_tree_cost5` 在 2026-08-31 至 09-11 的历史模拟使用 $100,000 初始资金：毛收益 $15,917.43，假设成本 $4,158.57，净收益 $11,758.86。成本约占毛收益 26.1%。它是价格特征树模型，不是 LOB 策略；5 bps 是单边成交额的模拟成本假设，不是 Alpaca 的固定收费，也不是已经测得的价差加额外滑点。

2 bps 与 5 bps 实验分别重新优化组合，因此订单不同。不能把两个结果直接当成同一批交易的纯成本差；固定订单敏感性需另看 `fixed_order_stress_5bps`。测量真实成本时需注明参考价格，避免把已包含在滑点中的价差再扣一遍。

市价单通常更容易成交，但成交价受流动性和路由期间的市场变动影响；限价单约束成交价格，却可能不成交。可立即成交的限价单也可能消耗流动性，因此“限价单”等于“Maker”并不成立。[Alpaca 订单说明](https://docs.alpaca.markets/us/docs/orders-at-alpaca)

做市需要处理库存风险、成交不确定性等问题，不是单靠返佣获得确定收益。[Avellaneda–Stoikov 作者页面](https://www.sashastoikov.com/finance/2015/3/9/high-frequency-trading-in-a-limit-order-book)

目前没有证据认定项目必须改成 Maker，也不能假定用户账户能获得交易所返佣。TWAP/POV 是拆单方法，不自动产生 Alpha 或保证获得价差。

## 接下来要验证的两条路线（尚未实现上线）

1. 预测路线：相同数据、资金、日期和成本条件下，比较价格基准与价格 + 真实 L1，报告多个未来收益周期；保留失败候选。
2. 执行路线：保持组合目标一致，比较当前执行与候选限价/拆单策略，测量成交率、到达价偏离、未成交机会成本和成交后价格变化。没有队列数据时不得假定挂单碰价即全额成交。

当前默认交易策略仍是价格成交量 Ridge。真实 L1 采集与研究链路尚未证明盈利，旧 Wave 不再输出实时交易信号。这次看板修正没有改动交易策略或原始模拟收益。

## 小团队的候选研究方向，不是收益承诺

- **相对价值**：MSTR 与 BTC/IBIT 可以研究动态对冲残差，但不是具有强制赎回机制的无风险套利。Strategy 官方说明其普通股不以跟踪 BTC 净值为目标；负债、优先股、稀释等均影响普通股价值。配对不会自动保证价差回归、消除全部 Beta 或达到 Sharpe > 2。[公司说明](https://www.strategy.com/notes)
- **动态股票池**：盘前相对成交量、缺口、流动性可以作为候选排序特征。应保存每天选择时已知的数据，避免按事后全天波动选股。RVOL > 300%、Gap > 3%、固定 5–8 股都是待验证参数，不是机构标准。现有 context_tree 逐股训练；迁移到新股票需要足够历史数据或经过验证的跨股票模型。全日振幅不等于策略可捕获收益，高波动不能使成本忽略不计。
- **事件研究**：PEAD 与指数调整都值得研究，但不保证一到三天单边走势或确定利润。PEAD 研究发现交易成本可以解释相当部分观察到的收益；指数提供商也研究了指数效应随时间减弱的现象。需要当时可获得的公告时间、预期数据及交易成本。[PEAD 研究](https://business.columbia.edu/faculty/research/liquidity-and-post-earnings-announcement-drift)、[S&P DJI 研究](https://www.spglobal.com/spdji/en/research/article/what-happened-to-the-index-effect-a-look-at-three-decades-of-sp-500-adds-and-drops/)
- **执行改进**：固定本次树模型的单边总成交额 $8,317,130.22，假设成本从 5 bps 改成 2 bps，机械少扣约 $2,495.14，不能据此宣称利润翻倍。真实挂单会改变成交率、时间和持仓路径，不能只改成本数字。IEX 报价也不能直接称为全市场 NBBO；没有相应数据不能验证 NBBO 中点执行。

建议顺序：先完成固定树模型与基准的未来纸面模拟和实测成本对账，再验证动态池泛化与候选执行方式；相对价值、事件策略作为独立实验登记。任何路线都需要净收益证据，不以复杂模型数量或机构名称作为依据。
