# Quant AI：亏损核对、交易逻辑审计与逐日验证

审计时间：2026-09-12 至 2026-09-13（纽约时间）。审计基线 Git 提交：`fc6f367`。股票顺序：SNDK → TSLA → MSTR → NVDA。

## 核心结论

目前的问题首先是**账本、训练与实际输入、概率含义、订单状态和持仓执行没有对齐**。堆更多 Alpha、ML 或增加仓位，不能修复这些错误。Lab 的部分成果原来是随机/硬编码展示，它本身没有接入下单；不能把最近亏损直接归因于新增 Lab 页面。

当前代码可以复现负期望信号开仓、计算了初始止损却没有对应出场、空头盈亏归账遗漏。高级模型自报 AUC 约 0.48–0.50，也没有证明可靠方向优势。本报告区分“代码确定有错”“成交确实亏钱”和“某错误造成某笔亏损”：前两项有证据，最后一项因历史决策快照不完整，不能逐笔强行归因。

## 3. 四只股票分别定位

### SNDK：先处理主要亏损来源

最近周 -$5,553.60，占四股重算亏损约55.9%；多头亏 -$5,190.18，空头亏 -$363.42。9月8日09:35前后两个多头批次（20股和22股）都在09:44:23以约$1,749.28退出，分别亏约$641.44与$710.91；14:49的45股多头约21分钟后又亏$730.32。该股四天日内开盘至收盘收益为 -1.78%、+0.80%、-1.84%、-4.63%。这些事实说明主要损失在多头成交，而不是证明“反过来永远做空”有效。

先核对每个批次的真实风险、加仓成本与对应退出，再比较统一5m输入的趋势、反转和ML。当前旧/高级模型的多空语义没有修好前，P_win不适合作为加大SNDK仓位的证据。

### TSLA：持仓路径与日内方向不一致

最近周 -$1,165.38。9月9日09:47买入84股约$374.39，持有约78分钟后约$370.17退出，亏$354.18；9月10日148股多头约131分钟后亏$337.89。当天整体开盘至收盘上涨并不保证中途追入赚钱。需要验证真实进入时点和退出政策，而不是用全天上涨推断应该扩大多头。

### MSTR：小幅价格变动也能被仓位放大

最近周 -$2,301.84，其中多头 -$2,228.22。9月10日15:03买入695股约$130.08（约$90,406名义金额），15:55以约$128.59退出，单批亏$1,032.60。约1.14%的价格不利变化已经产生较大美元亏损；这笔实际成交比“胜率阈值应该是多少”更能说明仓位和退出需要统一评估。

### NVDA：多空都不能依赖当前同一概率

最近周 -$916.62，其中多头 -$691.02、空头 -$225.60。9月10日09:54的164股空头约108分钟后回补，亏$137.28；9月11日171股多头约9分钟后亏$217.17。全周日内走势偏弱仍有空头亏损，说明简单按当天方向选边也无法解决入场、反抽和退出问题。

上面引用的是FIFO匹配批次，不将它们包装成独立信号或完整策略回合。

## 4. 逐日向前研究的定义

输入为新获取的同源 Yahoo Finance 5m OHLCV，2026-07-27至09-11，每股34个完整交易日、2,652根K线。使用 `auto_adjust=False`，仅09:30–15:55的bar开盘时间戳，排除16:00盘后条目。保留原始数据、来源、范围和哈希于 [行情manifest](bars/manifest.json)。它们是事后获取的历史行情，可能包含供应商修订；不宣称是当时保存的逐笔报价快照。

固定候选：现金基准、3根动量、12根动量、3根反转、固定正则的Ridge ML；另列开盘买入/收盘卖出的比较基准。此处3根=15分钟，12根=60分钟。前一交易日之前的数据训练每个验证日的ML，最近3个已完成交易日作内部验证，然后冻结下一天的候选选择。每个测试日的ML仅重训到前一交易日；标准化也仅拟合训练数据。

特征只读取已完成bar，下一根开盘执行；标签从下一根开盘开始，且不跨交易日。成本按每侧2bps计算，另按相同已冻结策略做每侧5bps压力测试。所有股票以无杠杆目标敞口单独计算，不使用真实账户仓位、不模拟加仓、无联合资金占用约束，收益百分比不能换算成“原账户本来可以赚多少”。

这是新建的可检查研究基线，**不是原live_runner逐秒成交重演，也不是全市场最佳策略搜索**。理想化next-open成交、未建模借券/排队/冲击及bar内回撤；[Alpaca官方说明](https://docs.alpaca.markets/us/v1.4.2/docs/paper-trading)也明确模拟交易未覆盖多项真实交易成本与执行影响。完整记录所有候选，不能看完该日收益再倒选当天冠军。现金被研究选择不代表向交易系统加入亏损停机/锁定逻辑。
